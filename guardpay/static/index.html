Not connected

Send a backup copy to your own Google Drive with one click, so it survives this laptop dying. Needs a free one-time Google setup — see below.

Set up Google Drive connection
  1. Go to console.cloud.google.com and create a project (no card needed).
  2. Under APIs & Services → Library, enable the Google Drive API.
  3. Under OAuth consent screen, choose External and add yourself as a test user.
  4. Under Credentials → Create Credentials → OAuth client ID, choose Desktop app.
  5. Paste the Client ID and Client Secret it gives you below.
